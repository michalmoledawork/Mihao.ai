# Mihao.ai GitHub Pages Site

This folder contains the public website pages for Mihao.ai.

Files:
- `index.html` — main website
- `privacy.html` — Privacy Policy
- `terms.html` — Terms of Service

## Publish with GitHub Pages

1. Upload these files to the root of your public GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Click **Save**.
6. Wait for GitHub Pages to publish the site.

Your URLs will normally look like:

- `https://YOURUSERNAME.github.io/mihao-ai/`
- `https://YOURUSERNAME.github.io/mihao-ai/privacy.html`
- `https://YOURUSERNAME.github.io/mihao-ai/terms.html`

Use those in the TikTok Developer Portal for the Web/Desktop URL, Privacy Policy URL and Terms of Service URL.
